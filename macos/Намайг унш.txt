====================================================================
               MONGOLMIC V4 - MACBOOK (macOS) СУУЛГАХ ЗААВАР
====================================================================

Энэхүү хавтас дотор Mongolmic V4 програмыг Macbook (macOS) систем дээр 
бүрэн native хурдаар, ямар нэг сааталгүйгээр ажиллуулах Swift / SwiftUI 
програмын эх код бэлэн боллоо.

Програм нь Windows хувилбартай яг ижил:
1. Цэсний мөрөнд (Top Menu Bar) байрлана.
2. Command + Option + Space дарахад дэлгэцийн доор Siri маягийн чамин,
   хөдөлгөөнт неон долгион гарч дууг бичиж эхэлнэ.
3. Товчлуураа тавихад автоматаар дуусна.
4. Gemini API руу өндөр хурдаар илгээж (Thinking унтраасан тул маш хурдан),
   бичвэрийг идэвхтэй талбарт уусгаж шивнэ (Шивэх хурдыг тохируулах боломжтой).

--------------------------------------------------------------------
ХЭРХЭН АЖИЛЛУУЛАХ ВЭ? (Хамгийн амархан алхмууд):
--------------------------------------------------------------------

1. Энэхүү "macos" хавтсыг тэр чигт нь өөрийн Macbook руу хуулж оруулна.

2. Macbook дээрээ үнэгүй "Xcode" програмыг App Store-оос татаж суулгана.

3. Xcode програмыг нээж, "Open existing project" сонголтыг сонгоод
   энэхүү "macos" хавтсыг сонгон нээнэ.

4. Xcode дотор:
   - Дээд хэсгээс Target-аа "My Mac" гэж сонгоно.
   - Run товчлуур (Play icon) дээр дарахад програм шууд таны Mac дээр 
     ажиллаж, Цэсний мөрөнд (Menu Bar) "🎤" дүрс гарч ирнэ.

--------------------------------------------------------------------
АНХААРАХ ЗҮЙЛС (Permissions / Эрх олгох):
--------------------------------------------------------------------

Macbook дээр програмыг саадгүй ажиллуулахын тулд дараах 2 зөвшөөрлийг 
системийн тохиргооноос олгох хэрэгтэй:

1. Микрофоны зөвшөөрөл (Microphone Permission):
   - Програмыг анх нээгээд товч дарахад микрофон ашиглах зөвшөөрөл 
     нэхэхэд "Allow" дарна.

2. Хүртээмжийн зөвшөөрөл (Accessibility Permission):
   - Програм нь таны өмнөөс дурын цонх руу бичвэр шивж (Input Simulation), 
     мөн товчлуурыг дэлгэцийн гаднаас хянах (Global Shortcut) тул:
   - System Settings -> Privacy & Security -> Accessibility рүү орно.
   - Mongolmic хувилбарыг сонгож, эрхийг нь идэвхжүүлнэ.

--------------------------------------------------------------------
САЙЖРУУЛСАН ТОХИРГООНУУД:
--------------------------------------------------------------------
Mac хувилбарт зориулж "Тохиргоо" цонхонд шинээр:
- "Instant Paste" буюу агшин зуурт шууд хуулах горим 
- "Human Typing" буюу Windows дээрх шиг нэг нэгээр нь уусгаж шивэх горимыг 
  хоёуланг нь сонгох боломжтой болгож нэмсэн.
